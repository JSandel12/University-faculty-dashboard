# Дипломат.Онлайн — «Цифровой деканат будущего»

> **Конкурсный прототип** для соревнования *«Цифровой деканат будущего»*.  
> Все персональные данные, оценки, расписание и документы **полностью вымышленные**. Прототип **не является официальным сервисом МГИМО** и использует оригинальную геометрическую эмблему.

## Ключевые возможности

1. **Единый центр студента (`360px+` mobile-first + Desktop Bento)**
   - **Вход и профиль**: аутентификация с хешированием паролей (`scrypt` + соль) и `httpOnly` HMAC-сессией, профиль с факультетом, направлением, курсом и группой.
   - **Интерактивный 3D-пропуск студента (Студенческий билет)** на базе GSAP 3D-параллакса с переворотом на 180° и встроенным QR-кодом.
   - **Расписание**: режимы «Сегодня» / «Вся неделя», фильтр «Только изменения», цветовые бейджи для переносов аудиторий, замен преподавателей, онлайн-формата и отмен.
   - **Успеваемость**: понятная сводка «Как у меня дела с учёбой» (GPA, посещаемость, зачётные единицы, статус стипендии / предупреждения о пересдачах), оценки по 100-балльной шкале и даты ближайшей сессии.
   - **Заявки и справки онлайн**: подача заявлений в 2 клика, живая 3-этапная шкала статуса (`Подана → На проверке → Готова`) и **печать/сохранение PDF-справки с QR-кодом и ЭЦП**.
   - **Уведомления и Умный навигатор (`Cmd+K`)**: быстрый поиск по расписанию и моментальные ответы на частые вопросы студента.
   - **Кабинет сотрудника деканата**: отдельная роль для проверки и одобрения заявок (с комментарием), публикации переносов пар и рассылки объявлений.
   - **Двуязычный интерфейс (`RU / EN`) и тёмная тема (`Light / Dark`)**.

2. **Безопасность (проверяется на сервере)**
   - Пароли никогда не хранятся в открытом виде (`crypto.scryptSync` + случайная 16-байтовая соль + `timingSafeEqual`).
   - Встроенная **IDOR-защита**: студент не может открыть чужой профиль или чужую заявку даже при прямом запросе к `/api/requests/[id]` или `/api/students/[id]` — сервер возвращает `403 Forbidden`. В разделе «Профиль и защита» есть кнопка живой проверки этого сценария для жюри.
   - Все шрифты (`Manrope`, `Cormorant Garamond`, `JetBrains Mono`) подключены локально через `@fontsource` — сайт работает в РФ без VPN и без обращений к внешним CDN шрифтов.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Локально данные автоматически инициализируются и сохраняются в `./data/decanat-db.json`.

## Деплой на Vercel Free Tier (с постоянной БД Neon Postgres)

1. Загрузите проект в GitHub / GitVerse и импортируйте репозиторий в **Vercel**.
2. В настройках проекта Vercel добавьте переменную окружения:
   - `AUTH_SECRET` — случайная строка длиной от 32 символов.
3. В разделе **Storage → Marketplace** подключите бесплатную базу **Neon Postgres** (переменная `POSTGRES_URL` / `DATABASE_URL` подставится автоматически). При первом запросе приложение само создаст таблицы и заполнит демонстрационные данные.
4. Проверьте доступность выданного адреса из России без VPN.
