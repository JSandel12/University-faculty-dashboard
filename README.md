# Дипломат.Онлайн — «Цифровой деканат будущего»

> **Конкурсный прототип** для соревнования *«Цифровой деканат будущего»*.  
> Все персональные данные, оценки, расписание и документы **полностью вымышленные**. Прототип **не является официальным сервисом МГИМО** и использует оригинальную геометрическую эмблему.

- **Живое демо (Amvera Cloud):** [https://mgimoai-haithem.amvera.io](https://mgimoai-haithem.amvera.io) *(доступно из РФ без VPN)*

## Ключевые возможности

1. **Единый центр студента (`360px+` mobile-first + Desktop Bento)**
   - **Вход и профиль**: аутентификация с хешированием паролей (`scrypt` + соль) и `httpOnly` HMAC-сессией, профиль с факультетом, направлением, курсом и группой.
   - **Интерактивный 3D Кампус-пасс**: студенческий билет с 3D-переворотом на 180° и встроенным QR-кодом.
   - **Умный календарь (`PremiumCalendar`)**: режимы «Неделя / День / Месяц», фильтр «Только изменения», цветовые бейджи переносов аудиторий, замен преподавателей, онлайн-формата и отмен, переход к маршруту на карте кампуса.
   - **Успеваемость**: понятная сводка «Как у меня дела с учёбой» (GPA, посещаемость, зачётные единицы, статус стипендии / предупреждения о пересдачах), оценки по 100-балльной шкале и даты ближайшей сессии.
   - **Заявки, умный подбор ситуаций и талоны в каб. 214**: подача заявления в 2 клика или через сценарии *«Опишите ситуацию»* (в продакшене — подключение нейросетевой `LLM/NLP`-системы), живая шкала статуса (`Подана → На проверке → Готова`), электронный талон с QR и **генерация PDF-справки с QR-кодом**.
   - **Интерактивная карта кампуса и 3D-афиша (`Three.js`)**: трёхкорпусная схема (Корпус A, Новый корпус, Спорткомплекс) с поэтажными планами и 3D-глобус кампусных событий.
   - **Навигатор (`Cmd+K` / `Ctrl+K`)**: быстрый поиск по расписанию, заявкам и частым вопросам.
   - **Двуязычный интерфейс (`RU / EN`) и тёмная тема (`Light / Dark`)**.

2. **Кабинет сотрудника деканата (двусторонняя связка)**
   - Обработка очереди заявок с быстрыми комментариями и мгновенным обновлением статуса у студента.
   - Публикация переносов пар и рассылки объявлений по группам.
   - Изолированный дашборд сотрудника без лишних студенческих виджетов (навигация на десктопе и мобильное SVG-меню).

3. **Безопасность (проверяется на сервере)**
   - Пароли никогда не хранятся в открытом виде (`crypto.scryptSync` + случайная 16-байтовая соль + `timingSafeEqual` в `src/lib/security.ts`).
   - Сессия хранится в подписанной `httpOnly` HMAC-SHA256 cookie.
   - Встроенная **IDOR-защита**: студент не может открыть чужой профиль или чужую заявку даже при прямом запросе к `/api/requests/[id]` или `/api/students/[id]` — сервер возвращает `403 Forbidden`. В разделе «Профиль и защита» есть кнопка живой проверки этого сценария для жюри.
   - Все шрифты (`Manrope`, `Cormorant Garamond`, `JetBrains Mono`) подключены локально — сайт работает в РФ без VPN и внешних CDN шрифтов.

## Ключевые архитектурные решения

- **Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS v4**: единая кодовая база для UI и серверных REST API маршрутов (`/api/auth/*`, `/api/portal`, `/api/requests/[id]`).
- **Реальная серверная авторизация вместо UI-заглушек**: подтверждаемая на уровне API ролевая модель (`student` / `staff`) и Anti-IDOR.
- **Автономная генерация документов (`jsPDF` + `qrcode`)**: оформление справок и талонов происходит без внешних платных API.
- **Масштабируемость модуля обращений**: сценарный подбор в MVP спроектирован с заделом под интеграцию нейросетевой (`LLM/NLP`) системы для разбора нестандартных ситуаций.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Локально демонстрационные данные автоматически инициализируются и сохраняются в `./data/decanat-db.json`.

## Деплой (Amvera Cloud)

1. Проект собирается в production-режиме на Node.js 22 (`npm run build && npm run start`).
2. В настройках окружения задаётся `AUTH_SECRET` (случайная строка от 32 символов).
3. Актуальное развёрнутое демо доступно по адресу: [https://mgimoai-haithem.amvera.io](https://mgimoai-haithem.amvera.io).
